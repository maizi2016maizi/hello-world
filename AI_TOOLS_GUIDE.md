# AI工具使用指南 / AI Tools Usage Guide

## 中文版

### 1. 关于Gemini和其他AI工具

#### Gemini是什么？
Gemini是Google开发的大型语言模型AI助手，类似于ChatGPT。

#### 关于定价：
- **Gemini (免费版)**: Google提供免费版本的Gemini，您可以通过访问 https://gemini.google.com 使用
- **Gemini Advanced (付费版)**: 这是高级订阅服务，提供更强大的功能
- **GPT-3.5/GPT-4**: 
  - GPT-3.5是免费的（通过ChatGPT）
  - GPT-4和GPT-4o需要ChatGPT Plus订阅（每月$20美元）

#### 在GitHub上使用AI工具：
您当前正在使用的是 **GitHub Copilot**，它是GitHub的AI编程助手：
- GitHub Copilot Individual: 付费订阅（每月$10美元）
- 学生和开源维护者可以免费使用
- 企业版本也可用

### 2. 如何开始新任务

#### 在GitHub中创建Issue（任务）：
1. 进入您的仓库主页
2. 点击 "Issues" 标签
3. 点击 "New Issue" 按钮
4. 填写标题和描述
5. 点击 "Submit new issue"

#### 使用AI工具辅助编程：

**方法一：GitHub Copilot in IDE**
1. 在VS Code或其他支持的IDE中安装GitHub Copilot扩展
2. 开始编写代码时，Copilot会自动提供建议
3. 按Tab键接受建议

**方法二：GitHub Copilot Chat**
1. 在VS Code中使用Copilot Chat
2. 直接询问编程问题
3. 获取代码解释和建议

**方法三：在Issues中使用AI**
1. 在Issue中创建任务描述
2. 使用 @copilot 提及Copilot
3. Copilot会自动生成代码更改的Pull Request

### 3. 实用建议

- **从免费工具开始**: 先尝试免费的AI工具（如Gemini免费版、ChatGPT免费版）
- **明确任务描述**: 清晰描述您想要完成的任务
- **逐步学习**: 从简单任务开始，逐步尝试更复杂的功能

## English Version

### 1. About Gemini and Other AI Tools

#### What is Gemini?
Gemini is Google's large language model AI assistant, similar to ChatGPT.

#### About Pricing:
- **Gemini (Free Version)**: Google offers a free version of Gemini at https://gemini.google.com
- **Gemini Advanced (Paid)**: This is the premium subscription service with more powerful features
- **GPT-3.5/GPT-4**: 
  - GPT-3.5 is free (via ChatGPT)
  - GPT-4 and GPT-4o require ChatGPT Plus subscription ($20/month)

#### Using AI Tools on GitHub:
You are currently using **GitHub Copilot**, which is GitHub's AI programming assistant:
- GitHub Copilot Individual: Paid subscription ($10/month)
- Free for students and open source maintainers
- Enterprise versions available

### 2. How to Start a New Task

#### Creating an Issue (Task) in GitHub:
1. Go to your repository homepage
2. Click on the "Issues" tab
3. Click the "New Issue" button
4. Fill in the title and description
5. Click "Submit new issue"

#### Using AI Tools for Programming Assistance:

**Method 1: GitHub Copilot in IDE**
1. Install the GitHub Copilot extension in VS Code or other supported IDEs
2. As you write code, Copilot will automatically provide suggestions
3. Press Tab to accept suggestions

**Method 2: GitHub Copilot Chat**
1. Use Copilot Chat in VS Code
2. Ask programming questions directly
3. Get code explanations and suggestions

**Method 3: Using AI in Issues**
1. Create a task description in an Issue
2. Mention @copilot in the issue
3. Copilot will automatically generate a Pull Request with code changes

### 3. Practical Tips

- **Start with free tools**: Try free AI tools first (like free Gemini, free ChatGPT)
- **Clear task descriptions**: Clearly describe what you want to accomplish
- **Learn gradually**: Start with simple tasks and progressively try more complex features
